# 接口扫描升级：验证边界

用户要求通过游戏接口快速定位矩形区域内指定资源、等级及贼寇。验收必须包含真实坐标请求、真实返回字段和现场结果对照；不得用 UI 逐格采集冒充接口扫描。

当前已捕获游戏 TCP 流量，但没有解出地图请求、响应结构、会话协议。第一阶段修正工具能力声明和扫描入口，同时提供离线抓包摘要，帮助继续核对协议。第一阶段完成不代表接口扫描完成。

- `scan_region` 的 `source` 默认 `api`；尚无已验证适配器时立即报 `map_api_unavailable:protocol_not_verified`，不得启动 UI 任务。只有明确 `source=ui` 才可使用原有采集。
- `protocol_status` 和 `game_status` 按实际依赖、身份绑定和版本返回接口适配器就绪情况。连接与登录在扫描时验证；抓到数据包不等于能发起有效地图请求。
- 离线诊断只输出端点、包长、时序和载荷类型，不输出原始载荷、登录信息或令牌；不发起网络请求。
- 诊断处理 PktMon 导出的 Ethernet 和 Wi-Fi LLC 帧，验证 PCAPNG 块长度、截断、接口与字节序，标出未支持的帧和重复 TCP 段。
- 后续阶段必须先验证协议，再实现分块请求、会话复用、限速、取消、去重、资源/贼寇筛选与覆盖率；协议字段目前不预设。
- 不编写打地/打贼寇 skills，不执行派兵。
