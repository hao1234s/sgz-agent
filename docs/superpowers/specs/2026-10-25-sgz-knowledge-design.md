# 三国志战略版本地知识库

用户目标：采集武将、战法、基础机制，存入向量数据库供现有 DSH agent 检索。

现有项目只有地图观察和任务 SQLite。首版增加独立知识子系统，不依赖游戏窗口、OCR 或账号配置。

## 方案

采用本地 SQLite 原始字段 + Qdrant local 向量 + FastEmbed BAAI/bge-small-zh-v1.5（512 维）。SQLite 保留实体和来源并提供名称精确匹配；向量用于描述性问题。备选是远程向量服务（需要部署和凭据）或纯向量（数值、同名和版本处理较弱）。本地混合方式是实施选择。

公开官网资料页及其正常加载的公开内容接口为武将、战法来源。无需登录；不调用游戏服务器接口。基础机制采用官方社区文章中的简短事实整理，注明文章日期及社区攻略属性。首版不承诺全赛季完整性或最新数值。

## 数据和检索

实体携带稳定 ID、类别、名称、字段、正文、来源链接、抓取时间、来源发布日期、所属赛季、地区、版本核验状态及内容哈希。缺失的等级、赛季或日期保持未知；网站缓存时间不充当资料更新时间。图像、广告、列传不加入语义索引。

分段上限 350 字，保留标题、字段边界和来源，每段生成向量。精确名称优先，其他查询结合中文二元词匹配和向量排名；类别、地区、已注明赛季过滤。筛选赛季时不将未知赛季误认为匹配。

采集顺序请求、限速、有限重试、缓存、失败清单；重新抓取可恢复，重复入库幂等。更新实体后删除其旧向量段。索引失败不报告成功，标出未索引条目。来源数据仅作为资料，不作为工具指令。

## 接口和交付

独立 CLI 支持 crawl / index / search / status / serve；DSH 插件增加 sgz_knowledge_search 和 sgz_knowledge_status，由独立 Python worker 提供。知识存储在 .state/knowledge，模型缓存位于该目录。JSONL 导出可迁移。

验收：真实官网数据完成导入和 512 维向量化；曹操等精确查询及中文语义查询带出处；筛选、更新及恢复测试通过；现有 Python/Node 测试和插件构建通过。数据文件不提交 Git。不会因本次查询启动或操作游戏。
