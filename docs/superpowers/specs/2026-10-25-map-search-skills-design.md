# 区域检索、城池队伍与技能系统

用户目标：启动本机 agent，查询指定区域的资源与贼寇，以及主城、分城各队伍的位置，为以后派兵做准备。此次不编写打地/打贼寇技能，也不执行派兵。

## 实现选择

继续使用 Python + SQLite + OCR 执行器和 DSH 插件。地图采集与本地检索分开：前者通过既有校准导航更新证据，后者只读取最新观察，不控制窗口。相对于每次查询重新扫图，此方案可复用数据、展示缺失覆盖与过期状态。相对于另建技能解释器，复用 DSH 原生 skills registry / filesystem provider / skill tool，可获得 YAML 元数据、按需加载、热更新和宿主权限控制。

## 行为

- 矩形边界为闭区间；资源类型、目标种类、等级、数据年龄、分页可筛选。每个世界/图层/坐标先选最新观察，再筛选，避免复活已消失目标。返回证据、采集时间、覆盖数；空结果不代表未扫描区域没有目标。
- 增加可暂停/恢复的区域扫描，单任务最多 2500 点、每轮最多 900 秒；保持原 explore_region 的 25 点兼容限制。已有断点、身份核验、互斥和停止行为沿用。
- 贼寇从已校准详情区域识别，支持实际画面中出现的“聚义军”等名称；兵力和等级缺失时为空，冲突不猜测。
- 城池/队伍保存独立快照，主城/分城、所属城池、队伍编号、当前位置、目的地和状态分离。最新完整快照替换旧编制；不完整采集明确标记，不能声称包含所有队伍。读取路径须有截图校准，不猜按钮位置。
- skills 放在 D:/agent/skills/<name>/SKILL.md，接入宿主原生发现、摘要、正文按需加载和变更监听。提供项目技能目录/加载工具和说明，不写战斗技能。禁用模型调用的 skill 不可通过自定义工具绕过。
- 服务应在 DSH 加载插件时启动，失败可诊断，退出时释放；不能并存另一套地图控制服务。

## 约束与实机条件

保留现有身份/world 隔离及只读动作白名单。初版为 UI/OCR；用户随后明确要求接口层快速扫描，当前实现增加固定客户端只读 API，详见 protocol-scan 设计与 `docs/protocol-investigation.md`。UI 路径仍需要窗口权限和校准；API 无需前台。未获得实机证据的路径须报告未知，不能以测试数据冒充实机结果。

实现者决定：矩形输入、默认地图最大年龄 3600 秒、编制最大年龄 300 秒、查询分页最多 100 条；旧库无破坏迁移。直接在现有干净工作区修改以保留本机校准路径和已安装插件 rootDir。
